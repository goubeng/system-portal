# Lessons

- 多项目端口编号必须基于完整项目注册表持久分配，不能根据当前抽样项目临时重排。
- 同一业务的原生版和 Vue 版应作为两个实现条目展示，并在说明中标明替代关系；不能因为业务名称相同就让两个进程共享端口。
- 本机进程门户不得提供任意命令输入框；所有可执行文件、参数、工作目录和端口必须来自受控配置。
- Windows PowerShell 5.1 会误读无 BOM UTF-8 脚本中的中文；面向双击执行的 ps1 入口必须保持 ASCII，中文说明放 README 或由程序页面展示。
- 系统调度枢纽启动时只能启动门户自身，禁止自动启动任何业务项目；所有项目必须由用户在卡片上手动启动。
- 每个业务项目仍需保留独立启动能力，门户只是统一演示入口，不能成为项目运行的强制依赖。
- 演示模式使用后台隐藏进程，不弹出额外 PowerShell 窗口；浏览器关闭不代表服务停止，必须通过门户停止按钮或 stop-portal.ps1 结束。
- 门户卡片的文字与层级以用户给出的 ASCII 结构为准；即使此前移除了“访问地址”标签，后续明确要求展示时应恢复该标题，并保留原有操作能力。
- 卡片标题下方的终端标签仅需图标，PC端和移动端文字不在该行重复显示；访问地址分组内仍保留终端名称以区分链接。
- 当用户要求终端图标、版本和技术标签与卡片序号对齐时，应将这些元素放在标题行外，左边缘与序号一致，而不是缩进到系统名称列。
- 新旧版本切换采用等宽的胶囊分段状态，整体在卡片中水平居中；不要让文本宽度改变按钮尺寸或对齐。
- AI协作控制台的真实路径是 `E:\AI\协作文档\AI协作控制台`，这是 Vue/Vite 应用而不是 `AI-PM-Engineering-System` 纯文档目录；门户应按 npm 项目登记启动。
