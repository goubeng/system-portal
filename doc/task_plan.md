# Task Plan

## 目标

建立仅供本机使用的综合演示门户，按持久编号管理多个原生与 Vue 项目，支持查看技术架构、启动、停止、打开和查看日志，并提供 Docker Desktop 启动入口。

## 计划

1. [已完成] 审计 8 个现有项目的技术栈、入口、依赖和健康检查。
2. [已完成] 建立 01-08 项目注册表和每项目 10 个端口的可扩展槽位。
3. [已完成] 实现仅监听 127.0.0.1 的 Node 管理服务和静态门户页面。
4. [已完成] 统一 Vue 项目的端口覆盖与自动回退能力。
5. [已完成] 验证多项目启动、停止、打开、日志和 Docker 状态。
6. [已完成] 完成使用说明及后续新增项目规范。

## 安全约束

- 门户只监听本机回环地址，不允许局域网访问管理接口。
- API 只执行项目注册表中的白名单命令，不接受任意命令、路径或 PowerShell 文本。
- 只停止由当前门户进程启动并记录的子进程。
- 不自动创建、删除、迁移或恢复数据库。
