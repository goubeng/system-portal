# 综合门户启动说明

## 日常启动

推荐直接双击项目根目录下的 `start-portal.ps1`。

也可以在 `E:\AI\N8N-project\6-其他系统\system-portal` 目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-portal.ps1
```

启动成功后，浏览器打开：

```text
http://127.0.0.1:8484/
```

## npm 启动方式

如果不用脚本，也可以执行：

```powershell
npm run start
```

`npm run start` 等同于 `npm run portal`，会先构建门户页面，再启动 `server.js`，这是完整门户入口。

## 不要用 npm run dev 做日常入口

`npm run dev` 只启动前端开发服务：

```text
http://127.0.0.1:5172
```

它不是完整门户入口，不能作为统一启动、停止和管理各业务系统的日常入口。

## 停止门户

在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\stop-portal.ps1
```

这会停止门户，以及本次由门户启动并持有句柄的业务项目进程。
